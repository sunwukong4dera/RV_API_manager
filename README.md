# rv_api_manager

`rv_api_manager` — проект для удобной работы с API R-Vision SOAR.

## О проекте

В первой версии проект организован по отдельным модулям и файлам, что позволяет:

- создавать и поддерживать множественные адаптированные вызовы API;
- использовать обёртки для унификации обращений к API;
- упростить дальнейшую разработку и расширение функциональности;
- подробно документировать доступные методы;
- явно указывать обязательные и дополнительные параметры запросов.

В качестве основного инструмента для HTTP-взаимодействия используется библиотека [`requests`](https://requests.readthedocs.io/).

## Цель проекта

Сделать взаимодействие с API R-Vision SOAR более структурированным, предсказуемым и удобным для повторного использования в прикладных интеграциях и автоматизации.
